# Press package

Standard media kit for **American Tang Soo Do**.

Jeremy will supply facts later. Every `TBD` field stays empty until then. Do not invent history, ranks, quotes, locations, or bios.

## Contents

| File | What to fill |
| --- | --- |
| [FACT-SHEET.md](FACT-SHEET.md) | One-page facts: name, founded, location, style, contact |
| [BOILERPLATE.md](BOILERPLATE.md) | Short and long “about” blurbs for the end of releases |
| [BIO.md](BIO.md) | Spokesperson / instructor biography |
| [CONTACT.md](CONTACT.md) | Media contact |
| [BRAND.md](BRAND.md) | Logo usage; points at existing artwork |
| [FAQ.md](FAQ.md) | Questions the press actually asks |
| [releases/](releases/) | Dated press releases, one file each |

## Artwork already in the repo

- Master logo: [`/logo.png`](../logo.png)
- Facebook set: [`/assets/facebook/`](../assets/facebook/)

## How to use

1. Fill TBD fields as information arrives.
2. New announcement → add `releases/YYYY-MM-DD-slug.md` from the template there.
3. Send journalists this folder plus the logo files. Do not send `TBD` pages as if they were finished.
